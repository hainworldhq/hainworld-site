# HAIN World Site

Version: v0.2  
Status: Active public site

This repository contains the public website for **HAIN World**.

**HAIN World** is the public entry point to the broader **HAIN** system.  
Its role is to introduce the Hybrid AI Native direction through a clear external surface and help visitors understand how the system is organized across category, architecture, protocol, and productization layers.

## Role in the HAIN system

Within the current HAIN structure:

- **HAIN World** introduces the system
- **HAINATIVE** defines the category
- **HAINOA** explains the architecture
- **HAINPRO** maps and specifies the protocol layer
- **HAINIZE** operationalizes the system

This repository belongs to the first layer: the public entry point and system overview.

## What this repository contains

This repository currently contains:

- the public homepage for **HAIN World**
- the top-level narrative and orientation layer for the HAIN system
- public entry links to **HAINATIVE**, **HAINOA**, **HAINPRO**, and **HAINIZE**
- site assets such as favicon and OG image
- the domain configuration for `hainworld.com`

## What HAIN World is for

HAIN World is not intended to hold the full depth of the framework.

Its job is to provide:

- a stable public-facing identity
- a legible introduction to the HAIN system
- a clear explanation of the five-site chain
- a structured path toward deeper layers

## The five-site chain

The HAIN system is organized through five primary public sites:

- **HAIN World** — total entry and ecosystem overview
- **HAINATIVE** — category site for Hybrid AI Native systems
- **HAINOA** — open architecture layer
- **HAINPRO** — protocol atlas, comparison, and HAINP drafts
- **HAINIZE** — productization, adoption, and enablement layer
