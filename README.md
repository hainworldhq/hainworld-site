# HAIN World Site

Version: v0.1  
Status: Active public site

This repository contains the public website for **HAIN World**.

**HAIN World** is the public-facing identity of the **Hybrid AI Native** framework. Its role is to introduce the framework through a clear public entry point and make the broader system understandable through structured narrative, public links, and lightweight orientation.

## Role in the HAIN system

Within the current HAIN structure:

- **HAIN World** introduces
- **HAINOA** explains
- **HAINIZE** enables practical entry

This repository belongs to the first layer: the public entry point.

## What this repository contains

This repository currently contains:

- the public homepage for HAIN World
- public entry links to the architecture layer, whitepaper, and glossary
- site assets such as favicon and OG image
- the domain configuration for `hainworld.com`

## Where to start

Start with:

- `index.html` — the main public-facing homepage
- `CNAME` — domain binding for `hainworld.com`

## Working summary

This repository is the public-facing website layer of HAIN.

Its purpose is not to hold the full depth of the framework, but to provide a stable and legible public surface through which the broader HAIN system can be introduced.
